## Write Back Decoder
This component is driven by the rd bits from the instruction word. It controls which register recieves the load signal from the control unit.
* The structure used is a 32 long case statement where the decoder output follows the format of 32'h2, 32'h4, 32'h8, 32'h10, 32'h20, etc
* Because RISC-V architecture demands register x0 be hardcoded to 32'b0, the decoder can never send a load signal to the first register

## Program Counter
Very similar to the n-bit register, but needs additional functionality for the count (increment)
* The D input will be connected to MAR and will only accept 12 bit inputs
* The Q output will be the program address and therefore also needs to be 12 bits

## Bit Mask Logic
Coming out the data memory block, the bits need to be manipulated depending on if the operation was a load byte, load half, load word, load byte unsigned, or load half unsigned
* memory block cuts the data and either sign extends or concatenates leading zeros

## Immediate Processor
Depending on the instruction word the immediate (a constant built into the instruction word) is formatted differently
* The immediate processor creates all possible valid arrangements for the immediate
* All five possibilities are output by the immediate processor and are passed to a multiplexer to select the correct immediate for the instruction word

## IO Ports
All IO ports established in the DP file
* Does not include inter-module connections at this stage

## Return to Registers
* In the datapath, the registers are generated using a generate for loop, where the only thing that changes is which bit from the decoder connects to the load pin
