## Important Python Syntax Notes
async def
* Runs it asyncronously or as a "coroutine"
dut
* Stands for device under test, variable used by cocotb referring to the device under test
with open("filename.ext", "r") as ref:
* Python syntax to read a file
* If "r" is replaced with "w" this would wipe the file and allow you to write to it
* "as ref" creates a reference to this read line, ref is a variable name and can be changed
for line in ref:
* For loops in python are simplified compared to loops in C
* goes through every line in the referenced file
match = re.search(r"#\s*x(\d+)\s*=\s*(0x[0-9a-fA-F]+|-?\d+)", line)
* re.search() takes a pattern and checks if it exists in "line"
* the r at the beginning of the string tells it to read it raw
* #\s* checks if the line has a # in it followed by a space
	- \s means space
* x(\d+) checks for register syntax: x0, x1, ..., x31
* \s*=\s* looks at the = sign right after the register
* (0x[0-9a-fA-F]+|-?\d+) Checks for either a hex result or a decimal result
