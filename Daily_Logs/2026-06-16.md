## Final Setup
* In order to actually run the makefile, make needs to be installed on the device
	- Make is not native to windows, nor a subset of python, so MSYS2 UCRT64 is necessary
	- MSYS2 UCRT64 is a Linux style terminal which supports the Linux native make program
* Once in UCRT64, run: pacman -S ucrt64/mingw-w64-ucrt-x86_64-make
* The make executable should now be created, but windows terminal needs to be able to access it
	- Add MSYS64 UCRT64 to the device's environment variables
	- Add this line: C:\msys64\ucrt64\bin
	- Leave it close to the bottom
