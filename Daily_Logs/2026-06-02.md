## Write Back Decoder
This component is driven by the rd bits from the instruction word. It controls which register recieves the load signal from the control unit.
* The structure used is a 32 long case statement where the decoder output follows the format of 32'h2, 32'h4, 32'h8, 32'h10, 32'h20, etc
* Because RISC-V architecture demands register x0 be hardcoded to 32'b0, the decoder can never send a load signal to the first register

## Program Counter
Very similar to the n-bit register, but needs additional functionality for the count (increment)
* The D input will be connected to MAR and will only accept 12 bit inputs
* The Q output will be the program address and therefore also needs to be 12 bits
