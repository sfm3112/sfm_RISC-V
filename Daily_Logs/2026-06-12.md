## Finnishing the Assembly
The assembly goes through the R type instructions as well as most of the I types, finishing off with a simple branch loop.
Assembling the assembly follows these steps:
1. use cd in the terminal to change to project directory with the .s file
2. The following terminal command compiles the file: python -m bronzebeard.asm testSuite.s -o testSuite.bin
	* testSuite.s is the name of the Assembly file, testSuite.bin is the name given to the binary file
	* binary file cannot be read directly, must use another command to print it out to the terminal in hex
3. The following command prints out the hex instruction words: python -c "import pathlib; data = pathlib.Path('testSuite.bin').read_bytes(); [print(f'{i:08x}') for i in [int.from_bytes(data[q:q+4], 'little') for q in range(0, len(data), 4)]]"
	* ('testSuite.bin') should match the name given to the binary file
