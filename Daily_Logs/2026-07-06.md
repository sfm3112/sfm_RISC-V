## Changes to the Python test bench
* Added a "safe_format" function which checks for uninitialized values
	- Now if a value is ininitialized, it does not break the python testbench]
* Changed the sampling from taking place on MC0 to whenever the LDrd signal goes high
	- LDrd is the load signal for the registers to be written back to
	- This was done because the testbench indicated each instruction was successfully writing back one instruction word later than expected
	- The cause was determined to be a testbench flaw where the Instruction word would lead the testbench to look at the register for the next instruction word.
