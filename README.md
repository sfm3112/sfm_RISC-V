# Custom 32-bit RISC-V Processor (RV32I Core)
A custom 32-bit hardware processor designed in SystemVerilog, optimized for a word-addressable memory architecture.


## Project Overview
This project is an independent engineering initiative to design, verify, and implement a fully functional RISC-V CPU core capable of executing the base integer instruction set (RV32I).
