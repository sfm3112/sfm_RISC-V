## MC2
* Type R does not go to MC2, therefore that case can be left out
* The same is true for type is
* Type L needs to take the data extracted from memory and return it to a register
	- This requires WBsel to be set to LD_WB and LDrd to be set to 1 in order to route the data back to the register
* Type JR loads the program counter with MAR and stores the prior program address in a register
	- Requires the LdPC signal to write MAR to the program counter
	- Requires WBsel to be set to PCOUT to take the current program address and send it back to the registers
	- Requires LDrd to activate the correct register for write back
* Type S reveals a signal not yet implemented in the datapath and not in the control unit module: pR/W and dR/W
	- These signals are necessary to write data to the memory block
	- The signal to write data to the program memory should never go high as dynamically altering the program is risky and introduces potential security risks
	- However, future functionality to store whole programs to onboard memory may come in the future, likely triggered by an input peripheral
	- The signal to write data to the data memory block only needs to activate in MC2 for type S
