## Immediate Processing
After looking to implement the AUIPC, I realized more thorough processing for the immediate is needed.
* Each possible immediate format will be calculated by an "immediate processor" block, which passes all 5 possible formats to a multiplexer
* the select for the multiplexer can most simply be {IW[6:5], IW[3:2]}
* Although the multiplexer has 5 data inputs, meaning theoretically the select needs a minimum of 3 bits, I type having 3 different opCodes complicates the logic enough that a 4th bit is necessary

## Datapath & Schematic Updates
To accommodate the immediate processor and fix execution gaps for jump/link instructions, several modifications were made to the top-level schematic:
* Routed PCout as a new dedicated input to the writeback multiplexer (WB mux) to allow the saving of the return address ($PC + 4$) during JAL and JALR instructions
* Resolved a broken path on the ALU Res line by utilizing global label routing, ensuring it clean-connects straight to the register file writeback path
* Completed the bit-masking and alignment logic block on the output of DMout to handle sub-word loads (LB, LH, LBU, LHU) before passing data to the WB mux
* Maintained clean bus routing by naming the missing port on the WB mux to cleanly interface with the memory data subsystem

## ASM Chart Refinements & Timing Realizations
An analysis of edge-triggered (sequential) vs. level-sensitive (combinatorial) components revealed a timing hazard in the initial 3-cycle execution plan.
* **The Synchronous Load Constraint:** Because both the FPGA's Block RAM (PM/DM) and the internal Register File operate on sequential rising clock edges, a load instruction cannot fetch an address and write back data in a single cycle
* **The Mixed-Cycle Solution:** The ASM chart was refactored. Standard data processing, jumps, and stores remain on an optimized 3-cycle pipeline. Memory load instructions (Type I - Loads) were expanded to a 4-cycle execution path (MC3), allowing DMout a full clock cycle to propagate, pass through the bit-mask unit, and settle at the register destination.
* **Opcode Alignment:** Cleaned up structural typos within the ASM decision blocks to ensure all opcodes adhere strictly to the RISC-V 7-bit specification
* **Store Addressing:** Ensured the Store instruction path correctly utilizes the MAB + MAX address generation hardware to drive MARout during MC2, aligning it with the physical address port of the memory block
