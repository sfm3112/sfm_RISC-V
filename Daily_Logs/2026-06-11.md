## Cocotb Investigation
This section will walk through a step by step guide of how this was accomplished.
1. Python was already installed on this desktop as part of MSYS2, so this script was run in the terminal: python -m venv v_env 
	* python tells MSYS2 to look for a Python executable, the -m venv tells it to look for a module named venv and run it, and v_env is the name of the environment created
2. Next, in order to install cocotb, Windows security has to let it through using this script: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process 
	* Set-ExecutionPolicy tells the shell what was going to happen, -ExecutionPolicy RemoteSigned allows local scripts to run, but still prevents remote scripts from being run, -Scope Process contains the reduced security to only that shell session
3. .\v_env\bin\Activate.ps1 navigates to the virtual environment
4. Finally, the script to install cocotb and pytest: pip install cocotb pytest
	* cocotb interfaces Python testbenches with Modelsim communicating with HDL, pytest is what is actually running the testbenches
5. To ensure it connected, use: vsim -version
	* This should display the active version of ModelSim
6. In the Quartus project folder, create a file called "Makefile"
	* makefile in project includes sufficient commentation to reference directly
