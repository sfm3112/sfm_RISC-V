5. Re-set up the environment through MINGW32

## Guide to setting up the Environment
1. Install MSYS2 MINGW32
* From PowerShell: winget install MSYS2.MSYS2
* From UCRT64: pacman -S --needed mingw-w64-i686-gcc mingw-w64-i686-python mingw-w64-i686-python-pip mingw-w64-i686-make
2. cd to the project directory
* Locate the path: find /c/ -maxdepth 2 -name "msys2_shell.cmd" 2>/dev/null
* Path to the new directory: /c/newpath/msys2_shell.cmd -mingw32
3. From that directory, create a virtual environment: python -m venv .venv
* To delete the virtual environment, first deactivate it: deactivate
* Then delete it: rm -rf .venv
*To reopen the made virtual environment: source.venv/Scripts/activate
4. Globally bypass python version block: export COCOTB_IGNORE_PYTHON_REQUIRES=1
5. Tell the terminal where modelSim is located: export PATH=$PATH:/c/intelFPGA_lite/18.1/modelsim_ase/win32aloem
* Change path directory as appropriate
6. Validate the system configuration: cocotb-config --makefiles
7. Run the testbench simulation: make
